# Soul of the Inquisitor — исправление мерцания управления (Update 23)

## Что исправлено

В `lib/main.dart`, внутри обработки попадания по врагу (`Enemy.applyDamage`), убран микросдвиг камеры на каждом попадании. При автоматическом оружии он запускался много раз в секунду и создавал постоянную мелкую тряску игрового изображения во время удержания кнопки стрельбы, из-за чего элементы управления могли выглядеть мерцающими/дёргающимися.

Тряска камеры при получении урона игроком, взрывах и крупных событиях сохранена. Изменение не меняет частоту стрельбы, урон, управление прицелом или прогрессию.

## Файл

- `lib/main.dart` — заменён участок, который вызывал `triggerShake` при каждом попадании по врагу.

## Проверка

Архив проверен на целостность ZIP. Flutter/Dart SDK в среде подготовки отсутствует, поэтому `flutter analyze` и сборка APK здесь не запускались. Нужно проверить APK через GitHub Actions и протестировать удержание стрельбы на устройстве.
