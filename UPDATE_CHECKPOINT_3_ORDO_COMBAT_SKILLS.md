# Контрольная точка 3 — боевые доктрины Ордо

## Что реализовано

- В экран «Навыки» добавлен раздел «Доктрина Ордо» с шестью навыками: по три для Ordo Malleus и Ordo Hereticus.
- Разблокировка тратит очки навыков (SP), недоступна для чужого Ордо и требует предыдущий навык в соответствующей ветке.
- Состояние открытых доктрин хранится в `expansionSystems.ordoDoctrine` и сохраняется вместе с данными расширения. Текущий остаток SP дополнительно сохраняется как `ordoSkillPoints`.
- Доктринальные бонусы применяются непосредственно в обработке попадания пули и ближней атаки в основном Flame-цикле.
- «Печать защиты» уменьшает входящий урон на 6%; бонус применяется в обработчике получения урона игроком.
- В тесты добавлены проверки защитного бонуса и наличия трёх навыков у каждого из двух Ордо.

## Проверка

Архив собран из исходного проекта контрольной точки 2 с внесёнными изменениями. В этой среде Flutter/Dart SDK недоступны, поэтому `flutter analyze`, `flutter test` и сборка APK не запускались. Эти проверки должны выполниться в GitHub Actions.
