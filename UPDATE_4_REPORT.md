# Soul of the Inquisitor — Story RPG Update 4: Unique Field Objectives

## Основные изменения

- Добавлены уникальные сюжетные объекты для трёх полевых операций: вокс-реле, грузовая накладная и два архивных узла.
- Объекты имеют отдельную геометрию/цветовую схему и размещаются в фиксированных позициях тематических карт.
- Сюжетный объект засчитывается при физическом контакте игрока; дубликаты не дают повторную награду.
- Прогресс объектов сериализуется внутри `StoryCampaignSystem` и проверяется на допустимость для активной операции.
- Выход с первого этажа сюжетной операции остаётся закрыт, пока не собраны все обязательные объекты. После этого можно продолжить обычный бой.
- При сборе обоих архивных узлов появляется особое финальное столкновение с боссом-Стражем архива (использует существующую реализацию босса), которое также учитывается в цели операции.
- Схема сохранения расширения повышена до 9; схема сюжета — до 4. Старые сохранения мигрируют без потери существующих полей.
- Обновлены тесты кампании: проверяются обязательные объекты, их уникальность, сериализация и требование обоих архивных узлов.

## Ограничения

- Столкновение с объектом активирует его автоматически; отдельная кнопка «Взаимодействовать» пока не добавлена.
- Архивный Страж использует существующий класс `Boss`, а не отдельную модель/анимации босса.
- Карты остаются на основе существующего генератора Flame; для каждой операции используются тематическая схема, фиксированные сюжетные объекты и очистка препятствий возле объектов, но это ещё не полноценные вручную нарисованные уникальные уровни.
- Flutter/Dart SDK недоступны в среде подготовки, поэтому `flutter analyze`, `flutter test` и `flutter build apk --debug` не запускались. Сборка должна быть проверена через GitHub Actions.
