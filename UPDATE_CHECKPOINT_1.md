# Контрольная точка 1 — стабильность и оружие

## Реализовано в исходниках
- Кодекс использует одну вертикальную прокрутку для арсенала, миров, событий и досье; кнопка «Назад» остаётся доступной снизу.
- Главное меню можно прокручивать в портретной и альбомной ориентации, поэтому кнопки не обрезаются на низких экранах.
- Добавлены шесть видов оружия: психопушка, экзорцистский инцинератор и пистолет «Губитель демонов» для Ordo Malleus; осудительный болтер, арбалет освящённых кольев и инферно-пистолет для Ordo Hereticus.
- Все шесть добавлены в каталог данных, меню экипировки, боевой цикл, скорость атаки, обработку типов урона и процедурную отрисовку.
- Имена новых видов сохраняются в существующем поле `ranged`; старые значения enum сохранены в начале списка, а загрузка старых неизвестных значений по-прежнему откатывается к болтеру.
- Добавлены unit-тесты на полноту каталога, принадлежность Ордо, сериализацию и миграцию старых сохранений.
- GitHub Actions запускает `flutter analyze`, `flutter test` и `flutter build apk --debug` перед загрузкой артефакта.

## Ограничения проверки
В среде подготовки архива Flutter SDK недоступен, поэтому тесты и APK здесь не запускались. Успешность сборки должна быть подтверждена результатом GitHub Actions после загрузки проекта в репозиторий.

## Баланс и игровые параметры
Новые параметры подобраны как стартовые: психопушка — пробивающий варп-снаряд; инцинератор — короткий веер огня с поджиганием; «Губитель демонов» — средняя дальность и варп-урон; осудительный болтер — точный пробивающий выстрел; арбалет — медленный выстрел с высоким пробитием; инферно-пистолет — мощный короткодистанционный заряд с малым магазином. Числа нужно откалибровать по результатам реальных боевых тестов.
